This is an game engine built in FORTRAN.
I built as a term project for a programming language class. I am very proud of this.
It uses FORTRAN for all logic and game code, only using C as a way to call NCurses functions for ease of display.

I have three games created, Snake, Tanks and Dungeon. All three use the engine windows and logic.
Key features include: Signal system, collision detection, object inheritance and "easy" menus.
